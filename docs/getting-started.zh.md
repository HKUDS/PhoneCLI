# 快速上手

从下载 APK 到跑完第一条任务，大约十分钟。只需要手机本身和一个模型 API Key——
不需要电脑，也不需要数据线。

## 1. 安装

在手机上下载并打开 [`PhoneGo-0.4.4-arm64.apk`](https://github.com/HKUDS/PhoneGo/releases/download/phonego-v0.4.4/PhoneGo-0.4.4-arm64.apk)。

- **Android 14 及以上、arm64**。Python 运行时和虚拟屏 helper 只为 `arm64-v8a` 构建。
- 需要允许"安装未知来源应用"。MIUI 会弹一次确认，点「继续安装」。
- 之后的版本直接覆盖安装：每个版本都用同一把密钥签名。

## 2. 打开两个开关

PhoneGo 通过回环地址和手机自己的 `adbd` 通信，而它得先从系统弹窗里**读出配对码**
才能完成配对——所以顺序很重要：

1. **开发者选项 → 无线调试 → 打开。**
2. **PhoneGo 的无障碍服务 → 打开。** 在 App 里长按「设置」可以直接跳到系统设置页，
   也可以走 设置 → 无障碍 → PhoneGo。

然后打开 App：它会自己完成配对并启动 agent 服务，连接就绪时对话里会提示。如果提示
"还没有配对无线调试"，把无线调试打开再重进 App，或在「设置」里点「配对无线调试」。

> 为什么无障碍要先开：没有它，App 读不到六位配对码，就配不上对；agent 也只能靠截图，
> 无法按界面上的文字标签点击。

## 3. 配置模型

点「设置」→「模型设置」：

| 字段 | 填什么 |
|---|---|
| **提供商** | 12 项可选——DeepSeek 官方、DeepSeek、OpenRouter、智谱、阿里百炼、硅基流动、月之暗面 Kimi、OpenAI、Gemini、Anthropic、本地、自定义。选完自动填好 base URL 和模型名 |
| **API Key** | 你自己的密钥。用 Android Keystore 加密，只留在手机上 |
| **model / api base** | 可改；任何 OpenAI 或 Anthropic 兼容接口都能用，base URL 决定走哪种协议 |
| **视觉模型** | 可选；留空表示和上面用同一个模型 |
| **每条任务最多走几步** | 默认 35，即一条任务的预算 |

**保存时会自动测一次连接**，「测试连接」可以再测。App 不内置任何密钥：没填 Key 时 agent 会拒绝执行，并在
对话里说明。

## 4. 第一条任务

建议从不需要登录的任务开始，这样能看清整个循环：

```
打开设置，看看现在连的是哪个 Wi-Fi
```

```
在小红书上搜一下港大附近的酒店，挑一家，再去携程查今晚多少钱
```

第一条几秒钟就完成。第二条就是 README 里的跨 App 例子：两个 App、一个值从前者传到
后者、最后给出价格。

你应该看到：对话里步骤流不断增长，右下角有一块 agent 自己那块屏的缩略图，最后是一条
答案——外加一个问题：要不要把它停住的那个页面转到你的屏幕上。

## 5. 遇到问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 提示「还没有配对无线调试，先完成一次配对」 | 还没有配对身份 | 打开无线调试，重进 App 或点「配对无线调试」 |
| 能用，但重启后不行了 | 安卓重启会关掉无线调试 | 重新打开无线调试，App 会自己重连 |
| 任务在后台被杀 | 系统的清理回收了 App | 允许后台运行，省电策略设为「无限制」（长按「设置」） |
| 步骤流里显示「看图」而不是「重放」 | 这台手机上还没有这个 App 的地图 | 正常现象——地图需要先爬一次；期间由视觉兜底 |
| 某个 App 总是跑到你自己的屏幕上 | 它不在虚拟屏上运行 | 正常：PhoneGo 会跟过去操作，做完再搬回来 |

## 6. 它不会做的事

- **花钱。** 支付、下单、提交订单都会先停下来问你。
- **替你输密码。** 密码、验证码这类界面会交给你处理。
- **开箱即用所有 App。** 有地图的 App 重放很快；没有的走视觉模型，更慢也更费 token。
  地图按 App 在你手机上编译，随时可以重建。
