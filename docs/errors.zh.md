# 报错对照表

拿屏幕上出现的那句话来查。每一条写明：在哪里出现、是什么意思、怎么办。界面本身怎么用见
[使用手册](manual.zh.md)。

条目按出现时机分组；App 原文照抄的部分用 `反引号` 标出。

---

## 1. 安装阶段

### `解析包时出现问题`
**在哪** 点开 APK 后系统弹出的提示。
**意思** 安装包不完整或损坏，不是 App 本身坏了。
**怎么办** 对照 release 页面看文件大小（约 18 MB）和旁边发布的 SHA-256；重新下载一次，
或者用 `adb install` 推包。英文系统会显示 *There was a problem parsing the package*。

### 装不上，且手机是 Android 13 或更早
**意思** 需要 **Android 14 及以上、arm64**。
**怎么办** 没有 32 位或旧安卓版本；换设备。

## 2. 首次使用：配对

### `还没有配对无线调试，先完成一次配对。`
### `还没有可用的配对身份，请先配对无线调试。`
**在哪** 刚打开 App 时的对话里。
**意思** 还没有配对身份，App 因此根本不会启动本地 agent。
**怎么办** 打开**无线调试**，再在「设置」里点**配对无线调试**（或重开 App）。配对码是从系统
弹窗里读的，所以**无障碍服务要先开**。

### `无线调试当前是关闭的，PhoneGo 连不上自己的 adbd。`
**意思** `adb_wifi_enabled` 是 0。安卓在重启、切换 Wi-Fi 后会把它关掉。
**怎么办** 设置 → 开发者选项 → 无线调试 → 打开，再回来；App 会自己重连。

### `没有检测到配对弹窗（请在无线调试里打开「使用配对码配对设备」）`
**意思** 配对流程一直没等到那个带六位码的系统弹窗。
**怎么办** 在无线调试里点**使用配对码配对设备**，让弹窗开着，两分钟内回到 App 点
**配对无线调试**。

### `提示：无障碍服务未开启。没有它，PhoneGo 无法读取配对码，agent 也只能用截图…`
**意思** 就是字面意思：配不了对，而且之后 agent 只能按坐标点，不能按文字找按钮。
**怎么办** 长按「设置」chip → 无障碍服务；或 设置 → 无障碍 → PhoneGo。

### `启动配对失败：…`
**意思** 配对服务没起来。
**怎么办** 确认无线调试开着、无障碍已启用，重开 App 再试一次。

## 3. 发送任务

### `本地 agent 没有起来：java.net.ConnectException: Failed to connect to /127.0.0.1:8765`
**在哪** 点发送之后出现在对话里。
**意思** `127.0.0.1:8765` 是 App **自己**的本地服务，连不上说明 agent 没应答——不是你的网络，
也不是模型。0.4.4 起，与手机自身 adbd 的连接断了会自己重建一次，不再直接让任务失败。
**怎么办** 0.4.2 起 App 会等更久并**自动重启一次**；如果仍出现，那一行会注明「已经尝试自动
重启一次」。接着按顺序：确认无线调试开着 → 从最近任务划掉 App 重开 → 还不行就重新配对（见 §2）。

### `等待本地 agent 就绪…`
**意思** 启动后的前 20–30 秒是正常的：正在建虚拟屏。
**怎么办** 不用管。持续一分钟以上才需要处理。

### `任务没能提交：还没有配置模型密钥，点「设置」填入 API Key。`
**意思** 没有密钥，任务被拒绝，而不是在没有模型的情况下硬跑。
**怎么办** 设置 → 粘贴 Key → **保存**（保存会自动测一次连接）。

### `这条任务跑了 20 分钟以上，我先停止等待了。`
**意思** App 停止的是**等待**，不是任务。
**怎么办** 结果稍后仍会出现在「用量」里；或者把指令拆短再跑一次。

## 4. 任务进行中

### `PhoneGo 的后台进程卡住了（N 秒没有心跳）。`
**意思** 心跳文件超过两分钟没更新——解释器冻住或被杀。0.4.1 起 App 会先自动重启一次；
**能显示这句话，说明那次重启也没成功**。
**怎么办** 从最近任务里划掉 App，重新打开。

### `轮询失败：…`
**意思** App 在看任务时和自己的 agent 断了。
**怎么办** 重开 App；如果任务其实已经跑完，答案在「用量」里。

### 步骤行出现 `no_ui: nothing readable on the agent's display`
**意思** 子任务开始时虚拟屏是空的，通常是那个 App 自己退了。0.4.2 会先等 6 秒再判定。
**怎么办** 新版不用管；旧版重跑一次任务。

### 步骤结尾是 `— max_rounds`
**意思** 这个子任务把步数预算用完了（默认每条任务 35 步，多个子任务共享）。
**怎么办** 设置 → 高级设置 → 调大「每条任务最多走几步」（5–80），或把指令拆成两条。

### 步骤结尾是 `— partial` / `— planner` / `— handover`
**意思** 分别是：模型中途停了 / 规划阶段没能把指令对应到 App / 任务被有意交回给你。
**怎么办** 看回答正文，里面会指出是哪一步没做成；换个更简单的说法重跑通常就过了。

### `这个 App N 小时前弹过安全验证（第 N 次）`
**意思** 这个 App 对自动化弹过验证码，于是**该 App 七天之内不做地图重放**，改用看图一步步操作
——更慢、更费 token，但功能没坏。
**怎么办** 就让它用看图模式跑，或换一个 App。标记会自己过期。

### `打不开「X」：它的主界面声明为 singleTask，系统只会把它放回自己所在的那块屏幕…`
**意思** 这个 App 在虚拟屏上根本起不来。
**怎么办** 换一个 App；或者在「模式」里打开**托管**（在你的屏幕上操作）。

### `AdbError: not connected`
**意思** App 和手机自身 `adbd` 的连接中途断了。
**怎么办** App 会自己重建虚拟屏；如果反复失败，把无线调试关掉再打开，然后重启 App。

### `需要你回答：` / `PhoneGo 等你一下`
**意思** 任务有意暂停：验证码、登录、二选一，或者一笔花钱的确认。
**怎么办** 在手机上处理，然后在对话里回一句。长时间不回会被当作"拒绝"。

## 5. 模型与密钥

### **测试连接**下方出现 `❌ …`
**意思** 模型服务商拒绝了这次调用。
**怎么办** 看后面的详情：`401` 是 Key 错误或过期，`403` 是这个 Key 没有该模型权限，`404` 是
base URL 或模型名不对，超时则是网络问题。base URL 决定协议：`…/v1` 是 OpenAI 风格，
`…/anthropic` 是 Anthropic 风格。

### `本地 agent 没有响应，已触发重启；十几秒后再点一次「测试连接」。`
**意思** 这次测试连 App 自己的服务都没到达，**还没轮到模型**。
**怎么办** 等约 15 秒再点一次；agent 正在重启。

### `已清空密钥，agent 只能截图模式运行。`
**意思** 你保存了一个空的 Key。
**怎么办** 重新填入 Key。

---

## 6. 地图与爬取

### `这个 App 爬不了` / App 列表里显示 ⛔
**意思** 这个 App 在虚拟屏上起不来（同上文 singleTask），爬了也记不到东西。
**怎么办** 换一个 App，或用托管模式跑它。

### `没能读取地图列表：…`
**意思** 打开地图库时 agent 没有应答。
**怎么办** 重新点「地图」；反复出现就重启 App。

### 地图有了，但步骤里是 👁 不是重放
**意思** 这台手机上这个 App 还没有可用的地图，或者它的地图正处在风控冷却期（见 §4）。
**怎么办** 到「地图」里建一张；或者接受更慢的看图路径。
