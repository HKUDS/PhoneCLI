# PhoneGo 使用手册

这个 App 的每一项功能，按界面逐块说明。标签以中文界面为准（App 也可切成英文：
长按「设置」→ 语言）。

还没装的话先看 [快速上手](getting-started.zh.md)——本文假设已经配对、已经填好模型 Key。

---

## 1. 界面构成

```
┌──────────────────────────────────────────────┐
│ PhoneGo                          地图 用量 设置 │
│ ‹会话名› ▾                                   │
│  ┌────────────────────────────────┐  ┌──────┐│
│  │ 消息、步骤流、回答              │  │ 虚拟 ││
│  │                                │  │ 屏画面││
│  └────────────────────────────────┘  └──────┘│
│ [ 发消息给 PhoneGo…        ]  ⚡ 自动   ↑     │
└──────────────────────────────────────────────┘
```

| 元素 | 是什么 |
|---|---|
| **地图 / 用量 / 设置** | 右上角三个 chip |
| **‹会话名› ▾** | 当前会话；点开可切换、新建、删除 |
| **消息区** | 你的指令、agent 的步骤行、最终回答 |
| **虚拟屏画面** | agent 那块屏现在的样子；点一下放大，双指缩放、拖动平移 |
| **输入框** | 在这里打字，箭头发送 |
| **⚡ 自动 / 👁 看图** | 下一条任务用哪种模式 |

任务进行中，输入框上方会出现状态行「执行中… 已完成 12 步」，右边是**取消**。

---

## 2. 会话

点会话名打开列表。

| 操作 | 效果 |
|---|---|
| 选一个会话 | 切过去，原来那个完整保留 |
| **＋ 新会话** | 开一个空会话，之前的仍在列表里 |
| **删除当前会话** | 只删这一条聊天记录；手机上装好的地图和任务结果都不受影响 |

一个会话也是 agent 的记忆单位：同一条会话里它能引用之前做过的事。任务执行中不允许
切换会话——先取消。

---

## 3. 跑一条任务

输入指令、发送。会出现这些：

- **步骤行**——每个动作一行，按顺序。有地图时是
  `地图回放：进入「Hotel_search」的 5 个动作`；没有地图时是一步一行。
- **回答**——agent 用一句话收尾，不是日志。如果它停在某个你可能会接着用的页面，
  结尾会带一个问题：要不要把那个页面转到你的屏幕上。
- **部分完成**——只走通一半时会写「部分完成：」并说明原因。
- **取消**——在下一个安全点停下；已爬的地图和已经学到的东西都保留。

有些步骤需要你：

| agent 会问 | 你怎么回 |
|---|---|
| *这一步会花钱：「提交订单」，金额显示为 ¥2401。要继续吗？* | 回「继续」放行，回其他任何内容都取消 |
| *需要你回答*（验证码、登录、二选一） | 在手机上处理，然后随便回一句 |
| *PhoneGo 等你一下* | 同上——任务只是暂停，不算失败 |

花钱是在**点下去之前**拦住的：agent 会把屏幕上的金额读出来写进问题里。

---

## 4. 两种模式

发送按钮旁边的 chip 切换下一条任务的模式。

| 模式 | 怎么跑 | 什么时候用 |
|---|---|---|
| **⚡ 自动**（默认） | 路由 → 重放该 App 地图里的宏；只有地图答不上来的地方才用视觉模型 | 绝大多数时候；快好几倍，而且结果确定 |
| **👁 看图** | 每一步都由截图+模型决定 | App 还没有地图，或地图在某屏一直出错 |

自动模式自己会退回看图——不需要为了脱困手动切换。看图模式每一步都花模型调用。

---

## 5. 托管模式

**设置**面板里有一个勾选项：*用你的屏幕操作（托管）*。

| 关（默认） | 开 |
|---|---|
| App 在一块手机不显示的虚拟屏上跑 | App 在**你的**屏幕上跑，你能看见每一步 |
| 你照常用手机 | 任务期间手机被占用 |

有些 App 只肯在主屏运行——京东、淘宝这类会检查窗口是否可见的，只有托管模式能跑。
任务结束后 agent 依然会把屏幕还给你。

---

## 6. 地图

**地图**列出这台手机上已经编译好的地图。

每一条显示：哪个 App、记了多少屏和多少个动作、以及**落点**——地图的自测成绩：
随机挑几条路径重放，看是否落到记录的页面（`落点 4/4`，或「还没测过落点」，或「（旧数据）」）。

| 按钮 | 作用 |
|---|---|
| **固定使用** | 指定这个包用这张地图 |
| **重新测落点** | 再抽几条路径重放一次，约一分钟 |
| **重爬** | 重新建这张图；新的完成前旧的继续可用 |
| **删除地图** | 从手机上删掉，这个 App 回到「没有地图」的状态 |

### 建一张新地图

**＋ 构建新地图**会问三个参数：

| 设置 | 默认 | 含义 |
|---|---|---|
| **最多爬取屏幕数** | 50 | 记录这个 App 的多少屏 |
| **时间预算（分钟）** | 30 | 到点就收工 |
| **最大深度** | — | 从首页最多点几下；1 = 只进首页列出的页面 |

App 列表里每个 App 有标记：✅ 可以爬、📌 已有地图、⚠️ 可能起不来（可试）、
⛔ 试过，虚拟屏上起不来。

爬取在 agent 自己那块屏上进行，你可以继续用手机。进度会一行行显示在对话里，
完成后出现在**地图**列表。

---

## 7. 用量

**用量**统计 agent 花了多少。

| 区块 | 内容 |
|---|---|
| 每日图表 | 今天和最近几天每天消耗的 token |
| **按任务** | 每条任务的调用次数与 token，最贵的在前 |
| **按模型** | 同样的数据按模型拆开 |

只统计模型调用：重放一步不花 token，所以有地图的任务看起来会便宜很多。

## 8. 设置

点**设置**。这个面板就是模型配置。

面板刻意做得很短：两个要填的、一个用来验证的，其余收起来。

| 元素 | 说明 |
|---|---|
| **API Key** | 你自己的；用 Android Keystore 加密，不出手机。以 `sk-or-v1-` 开头的会自动选 OpenRouter，`sk-ant-` 选 Anthropic |
| **提供商** | 点开是 12 项列表：DeepSeek 官方、DeepSeek、OpenRouter、智谱、阿里百炼、硅基流动、月之暗面 Kimi、OpenAI、Gemini、Anthropic、本地、自定义。选完自动填好 base URL 和模型名 |
| **测试连接** | 发一次很便宜的调用；显示 `✅ 可用：` 或具体错误。**保存时会自动测一次** |
| **高级设置**（默认折叠） | **model**、**api base**（决定协议：`…/v1` 是 OpenAI 风格，`…/anthropic` 是 Anthropic 风格）、**视觉模型**（留空 = 用同一个模型看截图）、**每条任务最多走几步**（默认 35） |
| **花钱时不再问我** | 默认关闭。打开后支付/下单不再询问；会改动手机的 shell 命令也一并跳过确认。打开时会先确认一次 |
| **诊断** | 运行环境：Python 版本、虚拟屏 id、心跳时间，以及一个「立即重连」 |
| **配对无线调试** | 重新走一次配对流程 |
| **保存 / 取消** | 保存会重启本地 agent；正在跑的任务不受影响 |

## 9. 长按设置

按住**设置** chip，打开系统页：

| 项 | 打开什么 |
|---|---|
| **无障碍服务** | 读配对码所需那个服务的系统设置页 |
| **电池优化（后台运行）** | 把 PhoneGo 设为「不限制」，免得后台被清理杀掉 |
| **导出备份** | 把配对身份、地图、会话、模型设置打成一个 zip 存到「下载」。**里面的 API Key 是明文**——不要外传 |
| **导入备份** | 恢复那个 zip 并重启 agent；重装或换机后用它 |
| **语言 / Language** | 跟随系统 · 中文 · English |

## 10. 它会做与不会做

**会做：** 打开 App、点击、滑动、输入、读屏上的内容、把一个 App 里读到的值带到另一个
App、给你留一个可以接着操作的页面，并告诉你结果。

**不会：**

- **未经询问就花钱**——支付、下单、提交订单会先停下问你（除非打开了「花钱时不再问我」）；
- **替你输密码和验证码**——这类界面会交给你；
- **开箱即用所有 App**——没有地图的 App 更慢，也更费模型调用；
- **在锁屏时运行**——屏幕得亮着并已解锁；
- **保证一定成功**——App 会变，地图会过时。回答里写的是实际发生了什么。

## 11. 故障排查

App 能打印的全部提示，按原文收录在 [errors.zh.md](errors.zh.md)。

| 现象 | 原因 | 怎么办 |
|---|---|---|
| *还没有可用的配对身份* | 从来没配对过 | 打开无线调试，重进 App，或点**配对无线调试** |
| 能用，重启后不行了 | 安卓重启会关掉无线调试 | 重新打开；App 会自己重连 |
| 任务在后台被杀 | 系统清理回收了 App | 省电策略设为「不限制」（长按设置） |
| *PhoneGo 的后台进程卡住了（N 秒没有心跳）* | agent 进程死了或冻住 | App 会先自动重启一次；如果提示仍出现，再从最近任务划掉重开 |
| 任务结束后聊天看起来空了 | 旧版本会开第二个窗口，抢在存档落盘前读取 | 0.4.2 已修；旧版本重开 App，会话仍在「会话」列表里 |
| 没检测到配对弹窗 | 无线调试里没开「使用配对码配对设备」 | 打开它，两分钟内再点一次配对 |
| 步骤里显示 👁、没有重放 | 这台手机上还没有这个 App 的地图 | 正常；到地图里建一张 |
| 建地图一开始就 ⛔ | 这个 App 在虚拟屏上起不来 | 用托管模式，或换一个 App |
| **测试连接**失败 | Key、base URL 或模型名不对 | 检查 base URL 对应的是哪种协议 |
| 某个 App 总在你自己的屏幕上 | 它的页面是由系统放到默认屏的任务 | agent 会先搬回，最多两次；仍不行就跟过去做完 |

## 12. 术语

| 词 | 含义 |
|---|---|
| **地图** | 一个 App 的界面与动作之间关系的编译结果 |
| **宏** | 地图里一条有名字的路径（如 *Hotel_search*），可整条重放 |
| **重放** | 执行一条宏——确定性，不调用模型 |
| **落点** | 地图的自测成绩：抽样的路径里有多少条落回了记录的页面 |
| **虚拟屏** | 系统给 agent 建的、手机不显示的那块屏 |
| **托管** | 改成在你的屏幕上操作，你能看见每一步 |
| **花钱时不再问我** | 花钱的步骤不再询问 |
| **胶囊** | 悬浮窗，实时镜像 agent 那块屏 |
